Politique de Confidentialite - Baborensemble Derniere mise a jour : 3 octobre 2026 App : Baborensemble - com.baborensemble.app Editeur : Baborensemble Contact : contact@baborensemble.com 1. Donnees que nous collectons Pour vous permettre de reserver vos billets de bateau, nous collectons : Informations de compte : Nom, prenom, adresse e-mail, numero de telephone. Informations de reservation : Details du voyage (dates, ports, passagers). Donnees techniques : Type d'appareil, version iOS, identifiants anonymes pour le bon fonctionnement de l'app. Nous ne collectons PAS vos donnees bancaires. Les paiements sont traites par nos partenaires de paiement securises. 2. Comment nous utilisons vos donnees Creer et gerer votre compte Traiter vos reservations et vous envoyer vos billets Vous contacter pour le support client Ameliorer l'application 3. Partage des donnees Nous partageons vos donnees uniquement avec : Les compagnies maritimes pour confirmer votre billet Les prestataires techniques (hebergement, Firebase d'Apple/Google pour les notifications) strictement necessaires Nous ne vendons JAMAIS vos donnees. 4. Conservation Vos donnees sont conservees tant que votre compte est actif, et jusqu'a 3 ans apres votre derniere reservation pour obligations legales. 5. Vos droits (RGPD) Conformement au RGPD, vous avez le droit d'acces, de rectification, de suppression, et de portabilite de vos donnees. Pour exercer vos droits, contactez-nous a : contact@baborensemble.com Vous pouvez supprimer votre compte directement dans l'app : Profil > Se Deconnecter > Supprimer le compte. 6. Securite Vos donnees sont chiffrees et hebergees sur des serveurs securises en Europe. 7. Contact Pour toute question : contact@baborensemble.com
