Politique de Confidentialité - Baborensemble

Dernière mise à jour : 3 octobre 2026
App : Baborensemble - com.baborensemble.app
Éditeur : Baborensemble

1. Données que nous collectons

Pour vous permettre de réserver vos billets de bateau, nous collectons :

  • Informations de compte : Nom, prénom, adresse e-mail, numéro de téléphone.
  • Informations de réservation : Détails du voyage (dates, ports, passagers).
  • Données techniques : Type d'appareil, version iOS, identifiants anonymes pour le bon fonctionnement de l'app.

Nous ne collectons PAS vos données bancaires. Les paiements sont traités par nos partenaires de paiement sécurisés.

2. Comment nous utilisons vos données

  • Créer et gérer votre compte
  • Traiter vos réservations et vous envoyer vos billets
  • Vous contacter pour le support client
  • Améliorer l'application

3. Partage des données

Nous partageons vos données uniquement avec :

  • Les compagnies maritimes pour confirmer votre billet
  • Les prestataires techniques (hébergement, Firebase d'Apple/Google pour les notifications) strictement nécessaires

Nous ne vendons JAMAIS vos données.

4. Conservation

Vos données sont conservées tant que votre compte est actif, et jusqu'à 3 ans après votre dernière réservation pour obligations légales.

5. Vos droits (RGPD)

Conformément au RGPD, vous avez le droit d'accès, de rectification, de suppression, et de portabilité de vos données. Pour exercer vos droits, contactez-nous à : contact@baborensemble.com

Vous pouvez supprimer votre compte directement dans l'app : Profil > Se Déconnecter > Supprimer le compte.

6. Sécurité

Vos données sont chiffrées et hébergées sur des serveurs sécurisés.

7. Contact

Pour toute question : contact@baborensemble.com
